# Farm Connect Frontend

A Next.js 14 web application for the Farm Connect agricultural marketplace, connecting farmers directly with consumers in Karnataka.

## 🌾 Project Overview

Farm Connect is an IEEE internship project that aims to eliminate middlemen in the agricultural supply chain by providing a direct platform for farmers to sell their produce to consumers.

### Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **HTTP Client:** Axios
- **Form Handling:** React Hook Form + Zod
